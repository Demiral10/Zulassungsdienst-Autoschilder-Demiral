# Zulassungsdienst & Autoschilder Demiral

Website für Zulassungsdienst & Autoschilder Demiral, Bottroper Str. 104, 45356 Essen.

## Inhalt

- `index.html` – die komplette Website als einzelne HTML-Datei (Styles, Skripte und Bilder sind eingebettet)

## Lokal ansehen

Die Datei `index.html` einfach im Browser öffnen – es wird kein Server benötigt.

## Veröffentlichen mit GitHub Pages

1. Im Repository auf **Settings → Pages** gehen
2. Unter **Source** die Option *Deploy from a branch* wählen
3. Als Branch `main` (oder den gewünschten Branch) und den Ordner `/ (root)` auswählen
4. Speichern – die Seite ist danach unter `https://demiral10.github.io/Zulassungsdienst-Autoschilder-Demiral/` erreichbar

Eine eigene Domain lässt sich unter **Settings → Pages → Custom domain** hinterlegen.
